前向传播

通过上一轮训练的参数计算各个输出层的结果。

z1=XW1+b1z_1=XW_1+b_1 z1​=XW1​+b1​

  • 输入向量 X
  • 输入层到隐藏层的权重 W1
  • 输入层到隐藏层偏置 b1

a1=ReLU(z1)=max(0,z1)a _1=ReLU(z_1)=max(0,z_1) a1​=ReLU(z1​)=max(0,z1​)

  • 隐藏层到输出层的权重W2

a2=z2a_2=z_2 a2​=z2​

损失计算

用逻辑斯蒂回归中同样的交叉熵损失函数算出损失值。然而实际运算时只用进行softmax而不用算损失值，因为后面要对损失值求偏导数，这个过程可以被化简。

通过 Softmax 函数计算输出层的概率：

pi,c=eai,c∑j=1Ceai,jp_{i,c}=\frac{e^{a_{i,c}}}{\sum_{j=1}^C{e^{a_{i,j}}}} pi,c​=∑j=1C​eai,j​eai,c​​

  • pi,c 是指样本 i 对应类别 c 的预测结果
  • C 是总类别数
  • ai,c 是
通过交叉熵损失函数算出损失值：

L=−1m∑i=1m∑c=1Cyi,c⋅ln⁡(pi,c)L=-\frac{1}{m}\sum_{i=1}^m\sum_{c=1}^C y_{i,c}⋅\ln(p_{i,c}) L=−m1​i=1∑m​c=1∑C​yi,c​⋅ln(pi,c​)

  • m 是样本总数

  • C 是类别总数

  • yi,c 是指样本 i 对应类别 c 的真实标签

    满足如果样本 i 属于类别 c，那么 yi,c = 1，否则 yi,c = 0
