每个层的正向传播比较好理解，在之前的文档中也有详细的描述，这里就不再赘述了，但是由于之前模型的反向传播我直接效用了pytorch的库函数，并不了解其执行方式，这里来详细说说CNN中各个层是如何进行反向传播的。

反向传播

其实反向传播比较重要的就是计算三个量，本层权重和偏置的梯度，还有返回给前一层的梯度。

前两个用于本层的梯度更新，后者用于前一层的梯度更新。

全连接层（FC Layer）

对于全连接层有：

Z=X⋅W+bZ = X · W+b Z=X⋅W+b

  • ZZZ 为输出，XXX 为输入。

∂L∂W=∂L∂Z⋅∂Z∂W=∂L∂Z⋅X        (1)\frac{\partial L}{\partial W} = \frac{\partial L}{\partial Z} \cdot \frac{\partial Z}{\partial W}=\frac{\partial L}{\partial Z} \cdot X\ \ \ \ \ \ \ \ (1) ∂W∂L​=∂Z∂L​⋅∂W∂Z​=∂Z∂L​⋅X        (1)

∂L∂b=∂L∂Z⋅∂Z∂b=∂L∂Z                 (2)\frac{\partial L}{\partial b} =\frac{\partial L}{\partial Z} \cdot \frac{\partial Z}{\partial b}=\frac{\partial L}{\partial Z}\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ (2) ∂b∂L​=∂Z∂L​⋅∂b∂Z​=∂Z∂L​                 (2)

∂L∂X=∂L∂Z⋅∂Z∂X=∂L∂Z⋅W        (3)\frac{\partial L}{\partial X} =\frac{\partial L}{\partial Z} \cdot \frac{\partial Z}{\partial X}=\frac{\partial L}{\partial Z} \cdot W\ \ \ \ \ \ \ \ (3) ∂X∂L​=∂Z∂L​⋅∂X∂Z​=∂Z∂L​⋅W        (3)

权重的梯度 ∂L∂W\frac{\partial L}{\partial W}∂W∂L​ 利用公式1可求；

偏置的梯度 ∂L∂b\frac{\partial L}{\partial b}∂b∂L​ 利用公式2可求；

前一层的梯度 ∂L∂X\frac{\partial L}{\partial X}∂X∂L​ 利用公式3可求；

前两项通过乘以学习率对层内参数进行更新，最后一项传回前一层。

卷积层（Conv Layer）

如果把每一次卷积操作都看作全连接层的话其实在公式上卷积层和全连接层是完全一致的。

唯一不同的是每个点的输出是由多个输入通道和多个不同位置的卷积得出的，所以在计算层内参数梯度和反向传播输入梯度时较为复杂。

池化层（Pooling Layer）

池化层本身不存在层内参数，所以只需要前向传播前一层的梯度。

同样于卷积层，池化层的每个输出都收到多个池的影响，所以前向传播时每个点都要匹配不同的池子。

以maxPoolingLayer为例，每个池的输出梯度都只对一个输入的梯度有影响（池中最大的那个），所以在前向传播时就需要标记池的输入中最大值的位置，这个是比较特别的一点。

展平层（Flatten Layer）

他同池化层一样，不涉及层内参数，并且输入和输出是一一对应的，所以在反向传播梯度时就很方便，只要把输出梯度对应到输入即可。

激活函数层（ReLU Layer）

他也没有层内参数，输入和输出是一一对应并且形状完全相同的，唯一要做的就是就是看看输入值是否大于零，若是直接返回输入梯度，反之返回零。
