GRU

最近在用GRU做机器翻译。

数据集使用了 OpenSubtitles.en-zh 的四分之一，500万条。

用四张4090训练了7小时。

模型架构图

Ht=Zt⋅Ht−1+(1−Zt)⋅Ht~H_t = Z_t\cdot H_{t-1}+(1-Z_t)\cdot \widetilde{H_t} Ht​=Zt​⋅Ht−1​+(1−Zt​)⋅Ht​​

Ht~=tanh(Xt⋅Wxh+(Rt⋅Ht−1)⋅Whh+bh)\widetilde{H_t} = tanh(X_t\cdot W_{xh}+(R_t\cdot H_{t-1})\cdot W_{hh}+b_h) Ht​​=tanh(Xt​⋅Wxh​+(Rt​⋅Ht−1​)⋅Whh​+bh​)

Zt=Sigmoid(Xt⋅Wxz+Ht−1⋅Whr+br)Z_t = Sigmoid(X_t\cdot W_{xz}+H_{t-1}\cdot W_{hr}+b_r) Zt​=Sigmoid(Xt​⋅Wxz​+Ht−1​⋅Whr​+br​)

Rt=Sigmoid(Xt⋅Wxz+Ht−1⋅Whz+bz)R_t = Sigmoid(X_t\cdot W_{xz}+H_{t-1}\cdot W_{hz}+b_z) Rt​=Sigmoid(Xt​⋅Wxz​+Ht−1​⋅Whz​+bz​)

  • HtH_tHt​ 代表隐藏状态，是模型最重要的东西，从前一个状态传递到后一个状态。
  • Ht~\widetilde{H_t}Ht​​ 代表候选隐藏状态，代表隐藏状态的更新方式。
  • ZtZ_tZt​ 代表更新门，用来确定隐藏状态是原有值留存的多还是候选隐藏状态留存的多。
  • RtR_tRt​ 代表遗忘门，用来确定候选隐藏状态中前一个隐藏状态的留存度。

整体模型图

  • 有多个隐藏层时，把前一个隐藏层的输出作为下一个隐藏层的输入。

整体过程

  1. 文字数据集通过分词、词表和 embedding 层编码，变成了嵌入向量。

    我使用了jieba对中文进行分词；embedding 层采用腾讯的 light_Tencent_AILab_ChineseEmbedding （200维）预训练 embedding 层和数据集出现次数大于10次的词的交集，预训练的 embedding 被我冻结了，训练过程中不再更新；编码器GRU隐藏层我设置了三层，画图偷懒了。

  2. 把嵌入向量序列一个一个输入编码器GRU，将最后一次的隐藏层状态保存。

  3. 将最后一个隐藏层的状态作为解码器GRU的隐藏层初始状态，将其前一次的输出经过英文 embedding 层后作为输入，得到新的隐藏层状态。

    英文的 embedding 层我采用 glove.6B.200d （200维）预训练 embedding 层数据集出现次数大于10次的词的交集，也冻结了；同样解码器隐藏层我也设置了三层。

  4. 将解码器的隐藏层状态通过全连接层和 softmax 方式重新变回 token ，最后通过词表将 token 转化回文字进行输出。

    这里我只采用了单层全连接层。
